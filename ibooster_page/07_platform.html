電控煞車平台架構
i-booster + EHB 模組 · 四種東西在這張圖上流動:人的力、電、訊號、油壓
滑過或點選以單獨檢視一條迴路

四條路徑同時存在:人的力進 i-booster,電進馬達,訊號進控制器,油壓出去推分泵
這個平台在做什麼。 以 F28069 控制卡負責 i-booster 的馬達層(三相電流、位置、踏板行程追隨),MicroBox 負責上層策略與資料擷取,兩者以 CAN 交換命令與狀態,MicroBox 再以 TCP/IP 回傳 Host PC。液壓側由 i-booster 建壓後經 EHB 模組分送至四個分泵,並回授總泵油壓 P_Mc 與分泵油壓 P_wc;駕駛者踩踏力由 Load Cell 量測為 F_driver。
四條路徑分別是。 駕駛者機械輸入 F_driver → Load Cell → i-booster 推桿; 電力與驅動 電瓶 → Driver → 三相 U/V/W → i-booster 馬達; 電子訊號 CAN / TCP-IP / PWM,以及 V_DC、i_a/b、θ_Motor、X_padel、P_Mc、P_wc 等回授; 液壓 i-booster →（RR/FL、FR/RL）→ EHB →（RL、RR、FR、FL）→ 分泵。 虛線框代表感測器(Load Cell、Pressure Sensor)。
與原圖的差異。 方塊的相對位置沿用原圖,走線經過重排以避免交叉(原圖有數處線壓線);訊號的來源與去向未更動。 F_driver 進 MicroBox 沿用原圖的浮空箭頭畫法 —— 若真的從 Load Cell 拉線會橫穿整張圖,故改在標籤上註明來源。 原圖各方塊內嵌實物照片,此處改為線稿圖示。
此處未涵蓋。 i-booster 內部的兩級齒輪與滾珠螺桿機構(見作動原理動畫)、EHB 模組的內部油路與電磁閥配置、驅動板電路(TLP-250 隔離與 MOSFET)、以及各控制迴路的取樣率與時序,均不在本圖範圍。本圖是接線架構,不是機構圖也不是液壓迴路圖。
資料來源:碩士論文與《車輛研究測試中心期末研究報告書》之「電控煞車平台架構圖」。平台用於 i-booster 助力模式、踏板行程控制、駕駛者介入判斷,以及 i-booster + EHB 整合策略的驗證。
