兩支感知器、兩個未知數，怎麼一邊跑一邊把自己校正回來
參數估測器的內部：三個階段各估各的、卡爾曼濾波器怎麼把非線性換成線性、車速怎麼在輪速與加速度之間按滑差分權重
輪速要換成車速，得先知道輪胎滾動半徑 r_f；加速度要能積分，得先扣掉加速規偏移量 ε。 這兩個都量不到，而且會隨載重與坡度變。做法是讓估測器跟著車輛狀態分階段， 每個階段只估「這個階段估得準」的那一項，再把結果往下一階段交棒； 卡爾曼濾波器用一次換元 x = [1/r_f , ε/r_f]ᵀ 把原本非線性的關係變成標準線性問題； 最後車速不是二選一，而是依各輪當下的滑差查表分配權重 —— 滑差小的那一輪主導，兩輪都滑就讓給加速度積分。
主線：三個階段依序交棒 這個階段新估出來的那一項 本案相對文獻改掉的地方 假設不成立 / 簡報未載明 / 讀圖所得
01 問題：兩個未知數卡在同一條式子裡 而且它們會互相掩護
先看那台車。整個估測器的輸入只有三個訊號：一顆加速規、兩支輪速計 —— 底下所有的式子都是在問「這三個量得到的東西，能不能換出量不到的那些」。

前輪是非驅動輪。靜止、起步、滑行這三種狀態下可以假設它與地面之間沒有滑差 —— 這時輪子的線速度就是車速，輪角加速度乘上滾動半徑就是車輛加速度：
無滑差時，輪與車同一個加速度 r_f · α_f = a_x
但加速規量到的不是 a_x，中間差一個裝歪與坡度造成的偏移量 r_f · α_f = a_m − ε ε 是加速規量測偏移量：加速規裝不平、路面又有坡度，量到的縱向加速度含一個常數偏差。 車輛靜止時真實加速度為零，此時量到的值就是 ε 本身 —— 這是唯一能單獨看見它的時機。
麻煩在於這條式子裡有兩個未知數：r_f 與 ε。 半徑估大一點、偏移量估大一點，等號一樣成立 —— 它們會互相掩護。 所以不能一次解，要找「只剩一個未知數」的時機分別下手。這就是分階段的理由。

紅字是「這一格新估出來的那一項」，照簡報的標色。每一格都同時更新該階段的 ε （ε̂_s / ε̂_a / ε̂_n），因為坡度會變、偏移量不是一個固定常數； 但半徑只在它「看得見」的那一格被估出來：前輪在起步、後輪在滑行。
03 卡爾曼濾波器：用一次換元把非線性變成線性 狀態不是 r_f 與 ε 本身，而是 1/r_f 與 ε/r_f
直接把 r_f 與 ε 當狀態的話，量測式對狀態是非線性的 —— 半徑在乘號那一邊、偏移量在減號那一邊，得動用 EKF 之類的東西。 簡報的作法是把式子重排一次，換一組狀態，問題就變成標準線性卡爾曼：

狀態方程與量測方程 x_{k+1} = A_n x_k　　　y_k = C_{n,k} x_k
A_n = [ 1　0 ; 0　1 ]　　　x̂_k = [ 1/r̂_f,k 　 ε̂_k / r̂_f,k ]ᵀ
C_k = [ a_m,k　−1 ]　　　y = α_f,k
卡爾曼濾波器（估計更新 → 誤差協方差傳遞 → 增益） x̂_{k+1} = Φ x̂_k + L_n ( y_k − ŷ_k )　　ŷ_k = C x̂_k
M_{n,k+1} = F_n P_{n,k} F_nᵀ + Γ_n Q_e Γ_nᵀ
P_{n,k} = M_{n,k} − M_{n,k} H_nᵀ ( H_n M_{n,k} H_nᵀ + R )⁻¹ H_n M_k
L_n = P_{n,k} H_nᵀ R⁻¹ 三條式子就是一組 Riccati 遞迴：先把上一步的誤差協方差往前推一格（M）， 再用這一次的量測把它壓下來（P），壓下來的量決定這一次要多相信量測（L）。 Q_e 與 R 的實際數值簡報未載明 —— 見頁尾註記二。 符號在簡報裡混用了兩套（A_n/Φ/F_n 指同一個狀態轉移， C/H_n 指同一個量測矩陣），此處照原樣保留，見註記三。

為什麼換元值得

不換元就得用 EKF：每個取樣都要重算一次雅可比矩陣，而且線性化誤差會隨半徑估錯而放大。 換元之後沒有任何近似，只是代數重排，卻換到一個能在 10 ms 內跑完的標準線性濾波器。

C 會變不是問題

C_k = [a_m,k　−1] 裡有這一拍的量測值，所以量測矩陣逐拍改變。 但卡爾曼要求的是對狀態線性，不是要求 C 是常數 —— 時變的 C 照樣走同一組遞迴。

它什麼時候會壞

整條推導的前提是前輪與地面無滑差。ABS 作動時滑差最大，前提正好不成立 —— 所以煞車階段必須凍結參數，改用先前收斂的值配加速度積分往前推。

04 車速：不是二選一，是依滑差分配權重 而且前後輪各查各的表
參數估出來之後，r ω 就能當車速用了 —— 但只有在不打滑的時候。 加速度積分剛好相反：不怕滑差，但會累積漂移。所以兩者都用，問題只剩「什麼時候該相信誰」。
文獻的作法 —— 單一輪速對加速度積分 V̂_x,k = K_v r̂ ω̂_k + ( 1 − K_v )( V̂_x,k−1 + â_x,k T_s ) 只看一個 K_v，也就是只由「某一輪」的滑差決定要不要相信輪速。
本案的作法 —— 前後輪各自帶一個權重 V̂_x,k = K_f r̂_f,k ω̂_f,k + K_r r̂_r,k ω̂_r,k + ( 1 − K_f − K_r )( V̂_x,k−1 + â_x,k T_s ) 三項的權重加起來恆為 1：兩輪各一份，剩下的全部給加速度積分。 滑差小的那一輪權重升高、成為主要資訊；兩輪滑差都大時，權重自動讓給加速度積分。 改成前後輪各自查表，是為了避免單輪的量化跳動直接寫進車速。

這張表的形狀本身就是設計。尖峰窄（|λ| < 0.1）表示只有在幾乎完全不打滑時才願意大幅相信輪速； 兩側的直線段一路降到零，表示滑差一大就平滑地退出，不會在門檻上跳來跳去。 ABS 作動的那一兩秒滑差正好落在退出區 —— 這時車速幾乎完全由加速度積分撐著， 而積分能撐得住，靠的是第 02、03 節先把 ε 估乾淨。整條鏈到這裡才閉合。

註記

  1. 本頁的三階段與 09 頁的四階段是兩個版本。本頁照簡報畫，三個階段是 Stationary → Acceleration → Normal，轉移條件是 ω_f > 0 與 TPS ≃ 0%； 車速估測訊號鏈那一頁照 Stateflow 截圖畫，是四個階段 Static / Acc / Normal / Freeze，轉移條件是 [V_x > 5]、after(1,sec)、 [BrkLgh==1 && V_x>5]。兩者的「Normal」指的不是同一件事 —— 本頁的 Normal 是節氣門放掉的滑行（所以才估得到 r_r），那一頁的 Normal 是一般行駛。 簡報與 Stateflow 何者為最終實作，資料裡沒有寫，這裡不代它裁決。
  2. Q_e 與 R 的數值簡報未載明。兩者的比值決定濾波器要多相信量測、參數能漂多快， 是這個估測器唯一真正要調的東西 —— 但簡報只給了式子，沒有給值，這裡不補。
  3. 符號在簡報裡混用兩套。狀態轉移矩陣在不同式子裡寫成 A_n、Φ、F_n， 量測矩陣寫成 C、C_{n,k}、H_n。本頁照原樣保留、不統一， 以免看起來像是另一組推導。
  4. K–λ 曲線是讀圖所得。簡報只有一張內嵌圖，沒有解析式，也沒有標明 K_f 與 K_r 是否共用同一張表。本頁取三個可辨識的點 (0, 6×10⁻³)、(±0.1, 1×10⁻³)、(±1, 0) 以直線相連重繪，形狀與原圖一致，但不應該當成精確的查表值。
★ 這一頁只講估測器本身。 它前面的訊號怎麼進來（霍爾方波、eCAP 量寬度、CAN 打包）在 車速估測訊號鏈； 它後面怎麼拿去控制（路面識別、最佳滑差目標值、MISO 模糊控制器、三態電磁閥）在 機車 ABS 估測與控制鏈 與 路面識別與最佳滑差目標值。 本頁不重複那三頁的內容。
